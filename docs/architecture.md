# Mimari (onaylı)

- **Monorepo:** TypeScript, pnpm workspaces + Turborepo
- **Web:** Next.js (web + PWA), Tailwind CSS, shadcn/ui → `apps/web`
- **API:** NestJS → `apps/api`
- **Veritabanı:** PostgreSQL, tenant (salon) bazlı Row Level Security
- **Kuyruk / önbellek:** Redis + BullMQ
- **Paylaşılan paketler:** `packages/shared`, `packages/ui`, `packages/config`
